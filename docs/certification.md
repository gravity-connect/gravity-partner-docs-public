# Gravity Connect Certification

Gravity Connect is an open standard API developed through a [partnership](link to About page) between Virtual Peaker and DER OEMs.

The optional certification process verifies the quality of an integration’s functionality and validates that the partner meets security standards. Device partners (OEMs), DERMS vendors, and VPPs are all eligible for certification.

Certified partners are promoted on the Gravity Connect site and provided with a badge that can be displayed in collateral of their choosing.

Certification requires a one-time fee of $15,000, covering the testing and QA process.

# The Certification Process

**1. Build an integration**

    Following the [specification], build an integration that supports at least one enrollment flow plus telemetry data and commands for the applicable device type(s).

**2. Validate key workflows**

    Test that enrollment, unenrollment, telemetry data, and commands work as expected, using a real or simulated test device that both participates and opts out of events.

**3. Complete the security audit**

    Confirm that data is encrypted in transit, secure authentication is required for cloud access, and that change management processes are in place for databases that affect the integration.
